# Pandas-Sales-Data-Analysis-Project
This project focuses on analyzing sales data using Python Pandas in a Jupyter Notebook environment. The goal of this project is to practice real-world data analysis tasks such as data loading, cleaning, transformation, aggregation, and basic insights generation.
ools & Technologies Used

Python

Pandas

Jupyter Notebook

CSV Dataset 
The dataset contains the following columns:

Order_ID – Unique identifier for each order

Customer_Name – Name of the customer

Region – Sales region

Product – Product sold

Quantity – Number of units sold

Price – Price per unit

Order_Date – Date when the order was placed
